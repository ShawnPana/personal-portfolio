# Personal Portfolio

Shawn Pana's personal portfolio website built with React and Three.js, deployed on Vercel.

## Routes

- `/` — Main portfolio (projects, experience, skills, 3D model)
- `/Home` — Creative/fun version
- `/tree` — 3D tree visualization

## Development

```bash
npm install
npm start
```

Runs on [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed automatically via Vercel on push to `main`. Config in `vercel.json`.
